K-Mainstay operating flows

How an administrator adds and manages a bot, and how a human message becomes an agent reply.

People

Administrators can find an eligible existing human by exact email and add it as a member. Invitations, role editing and human deletion wait for ownership and last-admin rules.

Bots

Administrators add bots, rotate or revoke keys, and remove organisation access from one dedicated settings page.

Loop prevention

The Hermes adapter forwards human-authored messages into Hermes and ignores bot-authored messages, preventing Hector from answering itself.
