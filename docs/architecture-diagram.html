K-Mainstay deployed architecture

One dependency-light application, durable SQLite events, and an external agent runtime.

Persistence

Messages and realtime events commit together. WebSocket wake-ups query SQLite, so dropped in-memory notifications do not lose data.

Security boundary

Humans use server-side cookies; bots use hashed copy-once keys. Sensitive bot mutations require a human organisation administrator.

Deliberate simplicity

One binary, one process, one SQLite database. No Docker, queue, ORM, router dependency, or built-in model runtime.
