# K-Mainstay

K-Mainstay is an exploration of an **agent-first workspace**: a shared place where humans and AI agents communicate, work, and remain understandable.

## First product

> The simplest possible hosted chat where adding an AI agent takes roughly two clicks.

The first milestone is intentionally narrow:

> Hector can be added to a clean hosted chat in under a minute, and Michael can clearly see what Hector is doing while it works.

This repository is currently at the **idea and validation** stage. The documents describe hypotheses and proposed boundaries, not settled product facts.

## Product rule

For every feature, ask:

> Does this make it substantially easier to add, understand, communicate with, teach, supervise, or coordinate agents?

If not, do not build it yet.
